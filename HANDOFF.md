# Handoff

`dist/index.html`, `dist/styles.css`, and `dist/app.js` are the complete site. The four local WebP images in `dist/assets/` come from the mission trainer's production-vision artwork. Edit content directly; no build is needed. External links point to the current playable demo and its source repository.

The resource choice uses native buttons, `aria-pressed`, and a live result. Evidence disclosure uses native `details`. The scenario is deliberately illustrative, not a playable engineering simulation. Preserve the distinction between the demo, technical checks, and future concepts when editing.

Before any public release, verify the destination links, check the deployed layout on mobile and desktop, and review the original art's NASA graphic and applicable usage rights. The development counts are 67 core CPU tests and 16 staged browser checks; they do not establish human learning outcomes or full GPU acceptance.
