# ASTRA institutional website

This repository presents ASTRA to hackathon judges and education partners. It is separate from the Babylon.js game repository. Preserve the public, account-free experience and the distinction between the current demo, production vision, and proposed validation.

- Use English for website copy and documentation. The six-slide 30-second Portuguese elevator deck is the requested exception. Original prototype captures and supplied concept art can contain Portuguese text; identify them as source visuals.
- Keep coherent game-world scenes. Do not add domestic family photography, isolated HUD snippets, fabricated testimonials, NASA endorsement or claims of learning efficacy.
- `dist/` is a complete buildless static site. No external runtime, tracking, forms, uploads or credentials are required.
- Check local asset and anchor links, JavaScript syntax, meaningful interaction behavior and responsive layout when supported browser tools are available. Report unavailable browser QA honestly.
- Keep code licensing separate from illustration rights and third-party marks. Maintain source attribution, AI disclosure and actual commit history.
- `.openai/hosting.json` contains the existing deployment identity. Reuse it for updates. Do not create a replacement Site or change its public audience unintentionally.
